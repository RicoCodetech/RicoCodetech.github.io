01Sobre mí

Curiosidad, código y ganas de aprender

Soy Oscar, desarrollador backend y estudiante de Ingeniería Informática en la UNED. Me gusta entender cómo funcionan las cosas por dentro y convertir esa curiosidad en software claro, mantenible y fácil de probar.

Mi foco actual está en el ecosistema Java: aplicaciones con MySQL y buenas prácticas como testing, control de versiones y despliegue. Estoy construyendo una API REST con Spring Boot y disfruto especialmente diseñando la lógica y la estructura de datos antes de escribir la primera línea.

Fuera del backend también me interesan la seguridad y la tecnología blockchain. Estoy explorando la creación de smart contracts con Solidity y la idea de montar un pequeño SOC doméstico con una Raspberry Pi y un VPS. Aprender haciendo es mi forma favorita de avanzar.

Flujo de trabajo

Desarrollo asistido por IA

Trabajo con agentes de código y sigo de cerca su evolución. Los uso como parte de mi flujo diario, no como sustituto de los fundamentos: doy contexto, reviso las propuestas y verifico que todo funciona.

Herramientas

  • Warp
  • OpenCode
  • Claude Code

Warp y OpenCode son mi día a día; Claude Code sigue el mismo enfoque de agentes.

  1. Contexto Explico el objetivo, las restricciones y el estado del proyecto antes de pedir cambios.
  2. Planificación Divido la tarea en pasos pequeños y reviso el plan antes de ejecutar.
  3. Implementación Uso el agente para explorar, refactorizar o escribir tests, revisando cada diff.
  4. Verificación Ejecuto pruebas, compruebo el resultado y documento lo que ha cambiado.

La IA acelera el trabajo, pero las decisiones y la validación siguen siendo mías.
